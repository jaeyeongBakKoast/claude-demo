# 코드 정의서 (공통 코드)

화면의 선택 목록, 상태값 등 공통 코드를 둔다. **DB에 공통 코드 테이블이 있으면 그 DML이 기준**이고 이 문서는 그와 일치해야 한다.
코드를 추가·변경하는 스토리에서 DML과 이 문서를 함께 고친다.

| 코드 그룹 | 그룹명 | 코드 | 코드명 | 정렬 | 사용 여부 | 설명 |
|---|---|---|---|---|---|---|
| DEVICE_STATE | 장비 상태 | NORMAL | 정상 | 1 | Y | |
| DEVICE_STATE | 장비 상태 | FAULT | 고장 | 2 | Y | |
