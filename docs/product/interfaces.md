# 인터페이스 정의서 (시스템 간·외부 연계)

화면 ↔ 서버 API는 [api.md](api.md)에 둔다. 여기는 **시스템 경계를 넘는 연계**만 둔다: edge ↔ central, 외부 기관·장비.
연계는 양쪽이 동시에 바뀌어야 하므로 변경 시 양쪽 모듈의 코드와 이 문서를 같은 스토리에서 고친다.

## 목록

| ID | 인터페이스 | 송신 | 수신 | 방식 | 주기·트리거 | 관련 REQ |
|---|---|---|---|---|---|---|
| IF-001 | <장비 상태 전송> | edge/api | central/api | HTTPS REST (JSON) | <1분 주기, 실패 시 재전송> | REQ-F-001 |
