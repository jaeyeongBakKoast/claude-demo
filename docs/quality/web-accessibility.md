# 웹 접근성·호환성 점검

> 공공 웹은 웹 접근성 준수가 요구되는 경우가 많다. 기준은 과업지시서가 정한 「한국형 웹 콘텐츠 접근성 지침(KWCAG)」 버전을 따르고,
> **검사 항목 전체는 해당 지침 원문에서 옮겨 온다.** 아래는 스토리 리뷰 때 자주 놓치는 항목만 추린 것이다.

## 스토리 단위 체크 (화면을 바꾼 스토리)

| 분류 | 확인 |
|---|---|
| 대체 텍스트 | 의미 있는 이미지·아이콘에 대체 텍스트, 장식 이미지는 빈 `alt` |
| 색 | 색만으로 정보를 구분하지 않음 (상태에 텍스트 병기), 텍스트 명도 대비 |
| 키보드 | 모든 기능을 키보드로 사용, 초점 표시가 보임, 초점 순서가 논리적 |
| 레이블 | 모든 입력 요소에 레이블, 오류 메시지가 해당 입력과 연결됨 |
| 표 | 데이터 표에 제목 셀(`th`), 필요하면 `caption` |
| 제목 | 페이지 `title`이 화면마다 다름, 제목 요소 계층이 맞음 |
| 시간 제한 | 자동 로그아웃 등 시간 제한이 있으면 연장 수단 제공 |
