# <모듈 경로> 개발 가이드

코드 컨벤션은 `<루트까지 상대경로>/docs/conventions/<스택>.md`가 기준이다.
이 문서는 이 모듈 고유의 명령·구조·주의점만 다룬다.

## 명령

```bash
<빌드·테스트·실행·lint 명령. 어느 디렉터리에서 실행하는지 명시>
```

## 구조

- `<폴더>/` — <역할 한 줄>

코드를 읽으면 알 수 있는 파일별 설명은 쓰지 않는다. 폴더의 역할과 경계만 적는다.

## 주의점

<이 모듈에서 Claude가 실제로 틀린 적 있거나 틀리기 쉬운 것. 예:>
- <명령을 모듈 디렉터리에서 돌리면 안 되는 이유>
- <손으로 고치면 안 되는 생성 파일>
- <환경·프로파일에 따라 달라지는 동작>
